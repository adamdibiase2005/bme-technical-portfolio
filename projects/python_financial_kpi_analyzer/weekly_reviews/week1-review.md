# Week 4 Review

## What I completed

Built a reusable Python financial KPI analyzer.

The program reads company financial data from CSV files, checks the required columns and data types, identifies missing values, calculates financial KPIs, exports clean summary files, and creates charts.

Tested the analyzer using Intuitive Surgical and Stryker.

## What I learned

I learned how to use pandas DataFrames, relative file paths, functions, data validation, missing values, CSV exports, and matplotlib charts.

I also learned how functions make code reusable for more than one company dataset.

## What was confusing

Relative file paths and the difference between running code from the project folder and the `src` folder were confusing at first.

I also had to understand that `NaN` means a value is missing and should not automatically be replaced with zero.

## Main takeaway

I turned a manual Excel analysis process into a reusable Python tool that can analyze multiple companies without rewriting the calculations.
